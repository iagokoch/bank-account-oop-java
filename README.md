# bank-account-oop-java

Projeto da Semana 2 do roadmap de aprofundamento em Java ("Detox de IA" — Hard Learning), com foco em Orientação a Objetos pura, sem frameworks.

## Objetivo

Modelar um sistema de contas bancárias aplicando os quatro pilares da OOP:

- **Classes e objetos**
- **Encapsulamento**
- **Herança** (ex: `ContaCorrente` e `ContaPoupanca` estendendo `Conta`)
- **Polimorfismo**
